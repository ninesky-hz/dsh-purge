# 1.7.1 —— 借鉴上游 1.6.52–1.6.56

本版没有新功能，全部来自对上游 `kingcharleslzy-ai/dsh-purge` 的对照与挑选：我们这条分支从 `d39d248`（1.6.47 前后）分出，上游此后走了 33 个提交，这里挑出对我们真正有用的四处。

## 一、去掉「公共目标门」

| 项 | 内容 |
| --- | --- |
| 上游 | `73468cf` 1.6.52: drop the public-target gate inherited from upstream |
| 症状 | 装完后仍会装 `net-scope` 的 agent/pre-step 门禁：一旦攻击型任务解析到公网 IP，整轮输出被清空并回「不行,这是严令禁止的」——那是上游早期「只允许内网」的限制，与无限制模式直接冲突 |
| 改法 | `lib/index.js` 不再 import / 调用 `installRegionGate`；`lib/net-scope.js` 换成上游版本（673 → 412 行，删掉 261 行检测与拒绝分块），**保留**面板在用的 `readAllowText` / `writeAllowText` 文件 API |
| 验证 | `grep -rn installRegionGate lib/ test/ packages/` 为空；`lib/net-scope.js` 仍导出 `readAllowText`（:373）与 `writeAllowText`（:381，async） |

## 二、运行时链接：多架构识别 + 同位迁移

| 项 | 内容 |
| --- | --- |
| 上游 | `d80056a` migrate same-install runtime links and retain failure diagnostics；`b7b1e18` multi-arch runtimes |
| 症状 | 我们原来的 `ensureAppRuntimeLink()` 只认 `runtime/primary-runtime/…` 一种布局；遇到 `runtime/<arch>/primary-runtime/…` 会判 `missing_runtime`；遇到「链接指向本安装的架构容器」会判 `runtime_conflict` 直接放弃，官方更新把布局换掉后 CLI 就修不回来 |
| 改法 | 整体移植上游 `lib/runtime-layout.js`（52 → 109 行）：新增 `findPnpmEntry()` 探测两种布局；`ensureAppRuntimeLink()` 在「旧链接指向本安装容器」时执行 `migration: "architecture_container"`，外置目标仍保留冲突判定；失败路径区分 `backup_failed` / `link_repair_failed`，并带回 `failedLink` 与 `rollback` 结果 |
| 验证 | `test/runtime-layout.test.mjs` 移植上游完整用例，**17 / 17 通过**（含迁移、外置目标拒绝、回滚、备份失败） |

## 四、状态查询去掉重复 fs

| 项 | 内容 |
| --- | --- |
| 上游 | `d91d671` 缓存宿主身份证据（该文件我们这一支没有，只取适用的一半） |
| 症状 | 一次 `gatherState()` 会对同一批补丁目标重复 `realpathSync`（实测 465 次 ≈ 360 ms），`listDesktopInstallRoots()` 被 `isInsideDesktopInstall` 调用 951 次、每次都重新 stat exe 与 resources |
| 改法 | `lib/core.js`：`realNorm()` 加 `_realNormMemo`（只记成功解析的路径，`resetPathMemo()` 一并清空，避免缓存「还没创建」的判断）；`lib/desktop.js`：`listDesktopInstallRoots()` 按入参记忆（上限 64 条），`clearDesktopLocateCache()` 一并清理 |
| 验证 | 桌面 surface：冷启 **677 → 639 ms**、热查询 **502 → 481 ms**；Web surface：热查询 **10 555 → 157 ms**（首次仍走全盘兜底扫描，属设计如此） |

## 未采纳及理由

| 上游提交 | 为什么先不做 |
| --- | --- |
| `d91d671` 的 `desktop-identity` 身份证据缓存 | 上游那份 `lib/desktop-identity.js`（7002 文件 realpath）我们这一支根本没有，11 s 那笔开销在本仓库不存在；加缓存等于给不存在的热点做优化 |
| `3cc6d1b` / `7b21321` / `a9a7405` 面板状态「证据按次读取」重构 | 与 1.6.52 的排版改动落在同几行（`settings-form.js` / `page.js`），需要单独分支做，避免把两种 UI 改动搅在一起 |
| `eac2be2` `installed-package` 别名安装维护 | 改动横跨 `community.js` / `core.js`，要和安装器一起验证，留到 1.7.2 |
