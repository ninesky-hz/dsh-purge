# 1.6.52 — 面板「状态」页排版整理

## 问题

截图里的「状态」页有三类毛病：

1. **分组边界不清**：「维护：更新与本机备份」「本机备份」各自带不同的 `marginTop`，中间是一大片空白，看不出哪一段属于哪一组。
2. **危险操作与主操作并排**：「应用」「还原」「卸载」「刷新」四个按钮挤在一行，「还原」「卸载」两个红按钮紧贴主按钮，视觉上无法一眼分出主次。
3. **状态行拥挤 + 空状态孤立**：「63/65 条补丁已生效」与右侧「桌面端」挤在同一行；备份区没有备份时，只剩一个居中的「刷新备份列表」横在页面中间，既不像动作也不像说明；版本不一致的黄条也只是一行紧贴的文本。

## 改法

全部在面板层（`packages/purge-panel`），不动宿主、不改数据接口：

| 位置 | 改动 |
| --- | --- |
| `src/styles/page.css` | 新增 `.dshpp-section-head`（标题 + 底部分隔线 + 右侧动作）、`.dshpp-empty`（虚线卡片）、`.dshpp-hero-danger`（右侧分隔线分组）、`.dshpp-warn`（左侧 3px 强调边 + warning 混合底）、`.dshpp-page-foot`（分隔线 + 次要色）；hero 状态行改 `flex-wrap` + 基线对齐，「桌面端」改成圆角描边徽章 |
| `src/components/settings-form.js` | 「还原 / 卸载」包进 `div.dshpp-hero-danger`，与「应用」之间用 CSS 分隔线隔开 |
| `src/components/maintenance.js` | 「本机备份」标题与「刷新」合成 section head（按钮内置 loading 文案）；空状态改成 `.dshpp-empty` 卡片，含标题「还没有本机备份」与说明 |

间距沿用 4/8 节奏：分区间 26px、组内 10–12px、按钮间 8px；徽章与提示条都走 DSH 语义令牌，不硬编码颜色。
