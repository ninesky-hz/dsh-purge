# 1.6.51 — 「环境还没配好」提示压住侧栏：补上缺失的遮罩样式

## 问题

首页左侧栏顶部出现一条「环境还没配好」的提示，直接**压在侧栏标题上**（`Kimi 环境还没配好` 与工作区列表文字重叠），没有全屏遮罩、没有居中卡片，也没有任何视觉边界。

按设计它应该是一个模态：半透明全屏遮罩 + 居中卡片 + 两个按钮（暂不配置 / 去环境适配）。

## 根因

同一个组件的类名前缀和样式表对不上：

| 层 | 实际类名 |
| --- | --- |
| 组件（`packages/purge-panel/src/components/env-gate.js`） | `.dshp-auth-mask` / `.dshp-auth-modal` / `.dshp-auth-warn` / `.dshp-auth-ops`（**单 `p`**） |
| 样式（`packages/purge-panel/src/styles/base.css`） | `.dshpp-auth-mask` / `.dshpp-auth-modal` / …（**双 `p`**） |

四个类名一个都没命中，于是：

- 遮罩退化成普通 `div`，随文档流落在左上角；
- `position: fixed; inset: 0` 不存在，所以既没有全屏层，也不会拦截点击；
- 卡片、按钮组、警告块全部没有盒模型，内容直接贴边叠在侧栏文字上。

`.dshp-auth-mask` 在 `client.js` 里只出现在 JS 字符串（`closest(".dshp-auth-mask")` 与 `className = "dshp-auth-mask"`），从来不是 CSS 规则；旧脚本 `scripts/patch-client-dock.mjs` 里那份补丁式样式也没进入当前构建产物，所以「看起来有定义」是误判。

## 改法

1. `packages/purge-panel/src/styles/base.css` 追加单 `p` 的遮罩层样式（约 120 行）：
   - `.dshp-auth-mask`：`position: fixed; inset: 0; z-index: 10100`，flex 居中，半透明底 + `backdrop-filter: blur(2px)`，`overflow: auto`，`overscroll-behavior: contain`，并留出 `safe-area-inset-*`；
   - `.dshp-auth-modal`：`width: min(480px, 100%)`、`max-height: calc(100dvh - 32px)`、`overflow: auto`、圆角 + 边框 + 阴影，跟随 `--dsw-alias-*` 令牌；
   - `.dshp-auth-warn`、`.dshp-auth-ops`（右对齐、可换行）、按钮的 `min-height` / 圆角 / `:hover` / `:focus-visible`（2px 品牌色描边）/ `.primary` / `:disabled`；
   - `@media (max-width: 480px)` 收紧内边距。
2. `packages/purge-panel/scripts/build.mjs`：内联进包的文本统一把 `\r\n` 折成 `\n` 再写出。Windows 上 CSS 源是 CRLF，esbuild 当文本内联后会把 `\r\n` 带进 `client.js`，导致「同源码重建」与已提交产物只差换行、`npm run check:client` 误报 stale。

## 验证

```
npm run build:client   → Built dsh-purge-community@1.6.51: 640021 bytes
npm run check:client   → PASS: checked-in bundle matches source
npm run check:docs     → ✓ 文档版本一致：1.6.51
npm test               → 376 tests / 328 pass / 26 fail / 22 skip
```

26 条失败与 1.6.50 基线**同一集合**（installer / 备份 / 真实 CONNECT 等环境相关用例），本次改动没有新增失败；新增的 `test/ui-overlay-styles.test.mjs` 5 条全过，钉住：四个 `.dshp-auth-*` 规则存在、遮罩是 `position: fixed; inset: 0` 且含安全区、构建产物里同样存在、`client.js` 不含 CRLF、测试脚本已登记该文件。

装好 1.6.51 后重启 DSH，首页的「环境还没配好」会变成一个居中卡片，点「暂不配置」或「去环境适配」任一按钮即关闭。
